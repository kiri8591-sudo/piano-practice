# Piano Practice — prototype Flutter pour Windows

Prototype interactif du MVP : Accueil, Sessions, Projets, Objectifs et Semaine.

## Lancer sur Windows

1. Installer Flutter.
2. Ouvrir PowerShell dans ce dossier.
3. `flutter doctor`
4. `flutter pub get`
5. `flutter run -d chrome`

Le prototype peut être testé dans Chrome sans Mac ni iPhone.

## iPhone

Le code Flutter pourra ensuite être compilé pour iOS sur macOS avec Xcode, ou via un service de build macOS distant.
